# Support

Use GitHub Discussions or a support issue for configuration questions. Use the bug form for reproducible incorrect findings and the feature form for generic capability proposals.

Include the PackGuard version, Node.js version, operating system, redacted configuration, command, and a minimal neutral fixture. Do not post proprietary application source, credentials, customer data, or unpublished assets.

Security reports belong in GitHub private vulnerability reporting as described in [SECURITY.md](SECURITY.md).
