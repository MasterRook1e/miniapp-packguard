# Roadmap

## 0.2

- explicit subpackage manifests and per-subpackage budgets
- cached hashing for large repositories
- configurable rule suppression with expiry metadata
- improved source-location reporting for reference findings

## 0.3

- plugin contract for custom reference extractors
- optional package composition graph
- historical trend report across committed baselines

External user feedback and real package fixtures will determine priority. The project will not grow by copying application-specific rules into the generic core.
