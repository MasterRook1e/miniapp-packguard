# MiniApp PackGuard v0.2.0

A feature release that adds deterministic package-topology and subpackage-budget evidence to the dependency-free mini-app auditor.

## Highlights

- optional `app.json`-style topology analysis
- support for `pages`, `subPackages`, `subpackages`, and `tabBar.list`
- normalized page routes with traversal and absolute-path rejection
- duplicate route, duplicate root, overlapping root, and missing page-file findings
- deterministic ownership of selected files by the main package or one subpackage
- main-package, per-subpackage, and named package-root byte budgets
- total, text, asset, other, page-count, and file-count metrics per package
- package tables in console, JSON, and Markdown evidence
- public topology analysis and normalization library exports
- focused topology, boundary, report, demo, and exact packed-consumer tests

## Compatibility

Existing configurations remain valid because topology analysis is disabled by default. Configurations generated by `miniapp-packguard init` enable the new analyzer explicitly with illustrative repository-defined limits.

No existing report schema version, baseline schema version, CLI command, exit code, action input, or asset-reference behavior is removed. Reports gain an additive `topology` object.

## Release evidence

The release workflow re-runs the complete verification gate, packs the exact npm-format tarball, installs it into a clean temporary consumer, runs the installed CLI with topology enabled, validates the generated package graph, imports the installed library API, records SHA-256 checksums, and generates GitHub/Sigstore build provenance.

The same source verification is exercised on Node.js 20 and 22 across Linux, Windows, and macOS. Repository self-audit, composite-action smoke, Maintainer Contracts, and CodeQL are maintained as independent public checks.

## Scope and status

The topology analyzer reads static package declarations and the already selected file inventory. It does not compile templates, execute application code, emulate a device, or claim that a platform will accept the package.

This release contains no private application source, catalogue data, user data, proprietary asset, credential, customer configuration, or private Git history. It is a GitHub release and installable npm-format tarball; it does not claim npm-registry publication or independent third-party adoption.

See `docs/PACKAGE_TOPOLOGY.md` and `docs/RELEASE_ASSURANCE.md` for the behavior and evidence boundaries.
