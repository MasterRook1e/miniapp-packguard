# MiniApp PackGuard v0.1.1

This maintenance release makes the public repository's own PackGuard integration executable, reproducible, and honest about its evidence boundary.

## Highlights

- fixed the self-audit workflow to use the supported `--out` and `--report-dir` options
- added a schema-valid self policy with total, file, runtime, and fixture budgets
- added required-file, duplicate-content, path-collision, and symlink-boundary checks
- uploads JSON, Markdown, and SARIF self-audit evidence on every push and pull request
- removes temporary bootstrap transport data and duplicate issue forms

## Evidence boundary

The repository-wide self audit disables static reference extraction because the test suite intentionally contains synthetic unresolved asset paths. Reference extraction remains covered by focused unit tests, the demo smoke test, and the exact packed-package consumer test.

## Verification

The release gate runs linting, 11 unit tests, a deterministic demo audit, npm package allowlist validation, and installation/import/execution from the exact generated tarball.
