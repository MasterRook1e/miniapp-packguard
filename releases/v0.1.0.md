# MiniApp PackGuard v0.1.0

The first public GitHub release of the dependency-free package and asset auditor for mini-app repositories.

## Highlights

- Git-tracked and filesystem discovery modes
- total, text, asset, per-file, and custom-group byte budgets
- static asset-reference graph with unresolved and unreferenced findings
- SHA-256 duplicate-content detection
- case-insensitive and Unicode NFC path-collision checks
- required-file and baseline-growth policies
- deterministic console, JSON, Markdown, and SARIF reports
- CLI, library API, and composite GitHub Action
- Node.js 20/22 verification across Linux, Windows, and macOS

## Release evidence

The release workflow re-runs the complete verification gate, packs the exact npm tarball, validates it through the clean packed-consumer test, records SHA-256 checksums, generates a GitHub/Sigstore build-provenance attestation, and uploads those artifacts with the release.

The tag and release target the exact `main` commit that passed this gate; no prebuilt artifact or package from another commit is reused.

## Scope and status

This release contains no application catalogue, user data, product UI, proprietary asset, credential, or private Git history. It is a GitHub release and installable npm-format tarball; it does not claim that the package has been published to the npm registry or adopted by an independent third party.

See `docs/RELEASE_ASSURANCE.md` for the evidence boundary and verification commands.
